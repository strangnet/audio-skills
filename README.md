# strangnet audio skills

Audio-plugin know-how for AI coding agents: real-time-safe DSP, parameter and state design, JUCE 9 plugins (VST3, AU and CLAP), and Akai MPC plugins. The skills hold technical facts, rules and pitfalls only. They never prescribe a workflow, so they work alongside whatever process skills you already use, such as [strangnet-skills](https://github.com/strangnet/agent-skills).

> **Status:** early development (0.1.0, unreleased). Skills, install instructions and credits arrive with the first release; see `docs/specs/` for the plan.
